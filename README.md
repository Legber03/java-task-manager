# Java Task Manager

Консольный менеджер задач на Java. Учебный проект для практики ООП, работы с коллекциями, файлами и обработки ошибок ввода.

## Возможности

- показать список задач
- добавить задачу
- отметить задачу выполненной
- удалить задачу
- сохранять задачи в файл `tasks.txt`
- загружать задачи при запуске программы
- обрабатывать неверный ввод номера задачи

## Как запустить

1. Открой проект в IntelliJ IDEA.
2. Запусти класс `Main`.
3. Пользуйся меню в консоли:

```text
1. Показать задачи
2. Добавить задачу
3. Выполнить задачу
4. Удалить задачу
5. Выход
```

## Структура проекта

| Класс | Зачем нужен |
|---|---|
| `Main` | меню и ввод пользователя |
| `Task` | одна задача |
| `TaskManager` | список задач и операции с ним |
| `FileManager` | сохранение и загрузка из файла |

## Формат файла

Задачи хранятся в `tasks.txt` по одной на строку:

```text
Купить хлеб|false
Сделать ДЗ|true
```

- слева — название
- справа — статус (`true` / `false`)
